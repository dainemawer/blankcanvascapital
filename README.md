# Blank Canvas Capital

Marketing site for [Blank Canvas Capital](https://blankcanvascapital.co.za), built with Next.js (App Router), React and Tailwind CSS.

## Getting started

```bash
nvm use        # Node 22
npm install
npm run dev    # http://localhost:3000
```

## Scripts

- `npm run dev`: start the dev server
- `npm run build` / `npm start`: production build and server
- `npm run lint`: ESLint
- `npm run type-check`: TypeScript

## Environment variables

- `RESEND_API_KEY`: sends contact form emails (`/api/send`)
- `NEXT_PUBLIC_GA_ID`: Google Analytics measurement id

See `CLAUDE.md` for project conventions and content locations.
