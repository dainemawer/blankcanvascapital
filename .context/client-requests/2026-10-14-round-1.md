## Transitions (H4 / I2)

The reference site (https://www.stockdalestreet.co.za/) uses **fullPage.js 2.9.4** (jQuery): `autoScrolling: true`, each section fills the viewport and the wheel snaps one section at a time, with a dot navigation on the right and a short-footer last section. Options for this site, not yet chosen:

- A. Native CSS `scroll-snap` plus framer-motion fade/slide-in as each section enters view. No new dependency, keeps normal scrolling and accessibility.
- B. A fullPage-style library for the exact snapping feel. New dependency (ask first; fullPage v3+ is GPLv3/commercial), hijacks scrolling, and is awkward for the tall Investment Approach sections and on mobile.

## Asset conventions (applied 2026-10-14)

- Heroes: JPEG (q82, progressive), 1140px wide with the original aspect ratio kept (a narrower source stays at native width, e.g. Digs at 900px). The modal crops them with `object-cover` and the item's `position`, so very wide images (Teneo 3.2:1) lose their sides on small screens.
- Logos: PNG, 428x274, opaque white canvas, mark trimmed and centred at roughly 290px wide, matching the existing logos. The Lab logo source is only 224x60, so it is upscaled about 1.5x and slightly soft; ask the client for a vector or larger file if it matters.
- Replaced assets use new filenames (`-v2`) so Next's image cache and any CDN don't serve the old picture.
